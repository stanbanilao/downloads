# Thynkverse Public Downloads

Customer-facing release repository for approved **LIVE** Thynkverse products.

This repository is for compiled/downloadable release artifacts and release notes only. Product source code remains in private product repositories.

A download or installation does **not** grant a licence. Where licensing applies, the product must still activate successfully through Thynkverse Super Control before use.

Public release sequence:

`DEV / BUILD -> TEST -> VERIFY -> DEMO / PILOT -> VERIFY -> LIVE`

Only releases that have completed that sequence and are approved for public distribution belong here.
